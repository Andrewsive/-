# 触灯迎春 · 西溪灯影

西溪湿地春节白墙投影的日常轻互动原型。使用用户确认的效果图作为场景依据，九盏花灯、光纹、流迹和倒影由 Canvas 独立实时绘制。

## 打开试玩

在此文件夹运行 `npm start`，然后打开 http://localhost:4188 。需要 Node.js 20 或更高版本，无需安装任何依赖。页面需要通过 HTTP 打开；不要直接双击 HTML 文件。

1. 点击白墙底部任意花灯，或选择下方灯盏卡片，即可模拟实体感应装置。
2. 一轮约 7.6–9.2 秒：点亮 → 光纹扩散 → 曲线升起 → 灯体缩小 → 光点消散 → 原位恢复。
3. 不限制同时响应的花灯数量，九盏灯可以一起被唤醒，各自独立播放、完成后恢复。同一盏灯在播放期间不会重复触发。
4. “演示设置”可显示感应点、暂停/继续、重置、随机触发、调节 0.5–2 倍速度、开关环境微动。
5. “全屏展示”隐藏说明和控制标记，展示完整原图视域。浏览器不允许原生全屏时，自动使用窗口内展示模式。按 Esc 或右上角退出按钮返回。

快捷键：数字 1–9 唤醒对应花灯；F 全屏；空格暂停/继续；Esc 退出展示或关闭设置。键盘焦点和鼠标悬停均有高亮。

## 已实现

- 建筑与景观底板、原位置的“西溪且留下”题字、夜景、水乡画卷、月亮、梅枝和地面反光。
- 九种独立绘制的灯体：梅枝灯、锦鲤灯、宫灯、莲影灯、山水灯、花信灯、竹影灯、如意灯、月白灯。
- 梅花瓣飘散、鱼形光迹、莲瓣展开与水波、月光环绕、竹影风纹、如意卷纹等不同反馈；宫灯摆转，灯面纹样有细微变化。
- 可重入的独立时间线、不设同时升灯数量上限、九盏灯共同响应、同灯防重触发、完成后归位。
- 缓入缓出、贝塞尔运动路径、轻微侧向漂移、摆动、柔和光晕、拖尾与光点消散。
- 水面轻微波纹、灯下倒影变化、独立环境动画开关。
- 相邻两盏灯同时进入上升阶段时触发“邻灯共鸣”：两盏灯之间出现会呼吸的金色流光桥与沿线光点，并按灯型组合呈现花瓣、水纹鱼影、月晕、风纹或如意卷纹；任一灯离开上升阶段后柔和退场。九灯同时升起时可形成八组独立共鸣。
- 动态光效使用同一建筑遮罩，题字区域保留镂空，光效不会投到瓦片、天空、树木和地面。悬停标记也裁切在墙底线之上。
- 正常页面采用靠近白墙的视域，完整保留墙体；全屏恢复完整 4:3 参考图范围。

## 传感器输入

输入边界与动画状态逻辑分离。鼠标、键盘、下方卡片都调用同一个接口：

```js
window.triggerLantern('lotus');
// { status: 'started' | 'busy' | 'invalid' | 'loading', id: 'lotus' }
```

可用 ID 按从左到右依次为：

`plum`、`koi`、`palace`、`lotus`、`landscape`、`blossom`、`bamboo`、`ruyi`、`moon`。

也可以发送统一的浏览器事件：

```js
window.dispatchEvent(new CustomEvent('xixi:sensor', {
  detail: { id: 'lotus' }
}));
```

未来接入 WebSocket 时，将消息映射到同一接口即可。例如硬件服务发送 `{"lanternId":"lotus"}`：

```js
// 示例，当前版本没有建立真实硬件连接。
const socket = new WebSocket('ws://localhost:8080');
socket.addEventListener('message', event => {
  try {
    const { lanternId } = JSON.parse(event.data);
    window.triggerLantern(lanternId);
  } catch (error) {
    console.warn('未识别的传感器消息', error);
  }
});
```

串口或其他信号也只需转换成有效 ID；独立播放、防重复触发和自动恢复由动画引擎处理。

## 源码结构

| 文件 | 作用 |
| --- | --- |
| `dist/index.html` | 页面和展示控制 |
| `dist/style.css` | 响应式布局、控制面板、全屏展示 |
| `dist/app.js` | Canvas 渲染、建筑裁切、输入适配、特色效果 |
| `dist/engine.js` | 九盏灯集中配置、运动采样、状态机与独立时间线 |
| `dist/lantern-art.js` | 可复用的九种灯体绘制 |
| `dist/assets/` | 原参考图与清理后的场景底板 |
| `tests/engine.test.mjs` | 并发、防重、时间、暂停、速度、边界与恢复检查 |
| `server.mjs` | 无依赖本地预览服务 |

改灯的位置、时长、路径、触发范围和特色效果，优先修改 `engine.js` 中的 `LANTERNS` 配置。改白墙建筑边界或题字保护区，修改 `app.js` 中的 `wall`。

## 验证

`npm test` 运行七项自动检查，覆盖九盏同时响应、同灯防重触发、各自完成和再次触发，以及暂停、速度、边界与恢复；`npm run check` 检查脚本语法。控制面板与展示模式已在浏览器实际操作验证。

## 当前范围与限制

- 不包含约 15 分钟集体祈福仪式、扫码、手机端或后台管理。
- 尚未连接真实传感器、WebSocket 服务、串口设备和投影机，未进行现场硬件标定。
- 右侧灯盏采用较低的升起轨迹，让题字始终清晰；左侧有更高的运动空间。
- 河流、桥阁、建筑与树木是场景底板，交互灯体与光效为独立实时图层。背景底板由内置 imagegen 清理原图中的固定灯盏得到；被移除处的小范围纹理经过重建，提示词与素材说明见 `asset-notes.md`。
- 网页中的遮罩依据参考图坐标绘制；真实投影需要现场测量墙体、进行几何校正并按实际亮度重新校色。

仅需部署 `dist/` 目录即可静态运行；无账号、数据库和外部字体依赖。
